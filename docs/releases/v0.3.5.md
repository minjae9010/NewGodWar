# NewGodWar v0.3.5

능력 연출을 각 능력이 직접 정의하도록 정리하고, 재료 차감·아이템 지급과 게임 종료 후 참가자 정리를 개선했습니다.

## 능력 연출과 애드온 API

- 93종 내장 능력이 각자의 `style()`에서 색상과 시전·적중·상태 연출을 지정합니다. 전용 묠니르·룬·방패·날개 등의 Display 모델도 능력 코드로 옮겨 모양과 동작을 함께 관리합니다.
- 공통 창·방패·날개 모델은 재사용하고, 전용 모델은 능력별로 유지합니다. 지원 서버의 Display 생성·갱신과 구버전 파티클 대체 경로를 계속 사용합니다.
- `GodAbility`가 `AbilityVisuals`를 상속하며, 예제 애드온도 새 `AbilityStyle.builder(...)` 사용법을 보여 줍니다. 이전의 내부 `AbilityStyle.of(id)`, `AbilityTheme.of(id)`, `ObjectModel` enum을 직접 사용한 애드온은 새 API로 수정해 다시 빌드해야 합니다. [능력 개발 안내](https://github.com/minjae9010/NewGodWar/blob/v0.3.5/docs/wiki/ability-development.md)에 예제가 있습니다.

## 아이템과 게임 종료 정리

- 능력과 도박 비용은 일반 인벤토리·핫바의 재료를 정확한 수량만큼 차감합니다. 이름이나 설명이 붙은 재료도 사용할 수 있으며, 수량 부족 시 일부만 차감하지 않습니다. 방어구와 보조 손은 비용에서 제외합니다.
- 기본 아이템·능력 보상·도박 보상이 인벤토리에 모두 들어가지 않으면 남은 수량을 발밑에 떨어뜨립니다. 보상 스택을 복제해 원본 수량과 메타데이터를 보존합니다.
- 게임 종료 당시 접속하지 않은 참가자의 인벤토리·관전 상태·로비 복귀 정리를 다음 접속 때 수행합니다. 대기 기록은 재시작 후에도 유지하고 완료 후 제거합니다.

## 검증과 설치

- JDK 21 `clean build`와 단위 테스트 51개, Paper 1.12.2·26.3 능력 회귀 및 Paper 26.3 코어·명령어·복구 회귀 검사를 통과했습니다. 로컬 16·32·64명 TCP 부하 검사 도구도 추가했으며 사용법과 측정 범위는 [테스트 안내](https://github.com/minjae9010/NewGodWar/blob/v0.3.5/docs/testing.md)에 있습니다.
- 로컬 64명 60초 일반·URF 부하에서 접속·게임·재접속 정리 오류는 없었고 TPS는 각각 19.68·19.51이었습니다. 일반·URF의 틱 지연 p95는 48.4·50.7ms, 명령 응답 p95는 4.4·9.9초였습니다. URF 틱 지연과 명령 응답은 테스트 안내의 초기 목표에 못 미쳤으며, 해당 수치는 로컬 서버와 TCP 테스트 클라이언트를 함께 실행한 환경의 측정값입니다.
- 서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.5.jar`로 교체한 뒤 재시작하세요. 기존 설정은 유지할 수 있습니다.
