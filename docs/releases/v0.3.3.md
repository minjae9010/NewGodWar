# NewGodWar v0.3.3

신규 능력 3종을 추가해 총 93종을 지원하며, 기존 능력 13종을 이름에 맞는 전투 방식과 전용 이펙트로 개편했습니다. 플레이어당 하나의 능력을 배정하는 방식은 유지합니다.

## 신규 능력

- **중력술사**: 중력핵으로 공중의 적까지 끌어당기고, 예고 후 반발장을 터뜨려 밀어냅니다.
- **메아리 검사**: 검격이 남은 자리에 후속타를 반복합니다. 적은 타격 위치에서 벗어나 잔향을 피할 수 있습니다.
- **룬 세공사**: 화염·서리 룬을 최대 3개 설치하고 원할 때 함께 기폭합니다. 겹친 룬의 피해에는 상한이 있습니다.

## 이름에 맞는 능력 개편

| 능력 | 새로운 전투 방식 |
| --- | --- |
| 토르 | 묠니르 투척과 귀환, 도끼 적중으로 전하 축적, 전하를 소비하는 천둥 강타 |
| 아르테미스 | 은빛 사냥활과 초승달 표식, 같은 적에게 화살 3회 적중 시 추가 피해 |
| 헤르미온느 | 부양·장비 수리·상태 해제 주문 선택, 프로테고 보호막 |
| 크로노스 | 시간 좌표 기록과 위치·체력 되감기, 고정된 시간 감속 영역 |
| 오딘 | 두 까마귀의 정찰 표식을 소비하는 추적 궁니르 |
| 헤파이토스 | 화로 열기를 검·도끼 공격 강화 또는 방어구 담금질에 사용 |
| 아테나 | 아이기스로 첫 근접 공격 방어 후 반격, 전방 팔랑크스 진형 |
| 헤라 | 가까운 아군과 수호 서약 유지, 서약을 소비하는 두 사람의 회복 |
| 아누비스 | 심판 대상에게 받은 피해를 저울에 기록한 뒤 심판과 생명력 흡수 |
| 여왕벌 | 움직이는 표적을 쫓는 벌떼, 꿀벌집 영역에서 아군 회복 |
| 니케 | 날개 돌진, 적 처치로 얻은 월계관을 아군의 승전 축복으로 소비 |
| 데메테르 | 빵 보급, 곡식이 자란 뒤 세 번 회복하는 수확 영역 |
| 판 | 제자리에서 세 선율 연주, 이동하면 연주 중단 |

## 이펙트와 안정성

- 망치 궤적, 초승달 표식, 화염·서리 룬, 시계 바늘, 까마귀와 벌떼, 영혼의 저울, 서약 고리, 방패열, 날개, 곡식, 음표 등의 전용 입자·효과음을 추가했습니다.
- 입자 수와 표시 거리를 제한하고, 은신·관전자별 표시 여부 및 이펙트 설정을 반영합니다. 연출을 꺼도 전투 효과와 자원 소모는 유지됩니다.
- 개편 능력의 예약 작업과 임시 전투 상태는 사망·로그아웃·능력 변경·봉인 시 정리됩니다. 임시 표식이나 월계관은 서버 재시작 후 재생하지 않습니다.
- 지연 공격은 적중 시 대상의 팀·참가 상태·거리 등을 다시 검사합니다. 궁니르와 벌떼는 벽 뒤로 피할 수 있으며, 시간 되감기는 막히거나 위험해진 좌표로 이동하지 않습니다.

## 변경된 사용법

- 아테나의 책·인챈트 테이블 생성과 무료 청금석 보조를 방어·반격 능력으로 대체했습니다.
- 여왕벌은 이제 `/x`로 대상을 지정하지 않고 바라보는 적에게 벌떼를 보냅니다.
- 데메테르의 상시 재생은 수확 영역 안에서 받는 회복으로 바뀌었습니다.
- 헤르미온느의 레파로는 체력 대신 주 손 장비와 착용 방어구의 내구도를 수리합니다.
- 비용·쿨타임·조작법은 게임 안의 `/a`와 능력 도감, [능력 목록](https://github.com/minjae9010/NewGodWar/blob/v0.3.3/docs/wiki/abilities.md)에서 확인할 수 있습니다.

## 검증과 설치

- 단위 테스트 39개와 Paper 1.12.2·26.3의 능력 자동 회귀 검사를 수행했습니다. 신규·개편 능력 16종의 연계, 자원 소모, 피격·회복 상한, 대상 재검사, 연주 중단, 되감기 위치 안전성, 이펙트 호환성과 작업 정리를 확인합니다.
- 자동 릴리즈는 최신 지원 Paper 기동과 코어·능력·명령어·서버 복구 검사를 통과한 뒤 게시됩니다. 실제 다인전 밸런스와 클라이언트 화면은 자동 검사 범위에 포함되지 않습니다.
- 서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.3.jar`로 교체한 뒤 재시작하세요. 기존 설정은 유지할 수 있습니다.
