# NewGodWar v0.3.2

Minecraft 26.3 지원을 추가하고, 명령어·능력 피드백과 서버 재시작 후 게임 복구를 개선했습니다.

## Minecraft 26.3 호환성

- 지원 버전 판별, 개발 서버 기본값, 전체 Paper 호환성 매트릭스와 최신 버전 검사를 26.3까지 확장했습니다.
- Paper 26.3 build 21 / Java 25에서 플러그인 기동과 코어·능력·명령어 회귀 검사를 통과했습니다.
- Minecraft 26.3은 정식 출시 버전이며, 검증에 사용한 Paper 빌드는 ALPHA 채널입니다. 이후 Paper 변경에 따른 호환성은 해당 빌드에서 다시 확인해야 합니다.
- 배포 JAR는 계속 Java 8 바이트코드로 빌드합니다. MC 1.12.x~1.21.x 및 26.1.1~26.3의 서버 기동은 각 버전에 맞는 Java로 GitHub Actions에서 검사합니다.

## 명령어와 설정 화면

- `/gw game`, `/gw team`, `/gw ability`, `/gw settings` 단계형 명령과 한글 별칭, 간편 명령을 추가했습니다. 기존 명령도 유지합니다.
- 클릭 가능한 도움말 목차·검색·페이지 이동과 단계별 자동완성을 제공합니다.
- `/gw gui <화면>`과 `/gmenu <화면>`으로 설정 화면을 직접 열 수 있습니다.
- 관리자 쿨타임 초기화에서 본인·특정 플레이어·전체 대상을 구분하고, 잘못된 이름이나 인수로 전체 초기화가 실행되지 않도록 검사합니다.

## 능력과 게임 안정성

- 능력별 발동·실패·재사용 가능 안내, 속성별 파티클·효과음과 고급 능력 타이틀을 추가했습니다. `abilities.effects.*`에서 조절할 수 있습니다.
- 부두술사의 팻말 연결, 정확한 대상 이름·킬타임·팀·관전 상태 검사와 연결 정리를 개선했습니다.
- 인벤토리가 가득 찼을 때 능력 보상 아이템이 유실되지 않도록 처리했습니다.
- 게임과 능력 테스트 종료 시 시작 전 월드 복원, 재접속·종료 후 팀 상태 정리와 팀 색상 채팅 처리를 보완했습니다.
- 최신 Paper에서 비동기 월드 저장이 끝나기 전에 스냅샷을 복사하거나 서버를 종료해 메타데이터가 손상될 수 있던 경로를 수정했습니다. 스냅샷·복구용 저장은 디스크 쓰기 완료를 기다립니다.

## 서버 재시작과 복구

- 정상 서버 종료와 게임 종료를 구분하고, 다음 서버 실행에서 진행 중인 기본 게임을 이어갑니다.
- 팀·능력·기본 쿨타임·킬 수·탈락·관전·재추첨·경과 시간과 맵 스냅샷 정보를 저장합니다. 주기 저장 간격은 `game.recovery-save-interval-seconds`로 설정합니다.
- 강제 종료 후에는 마지막 저장 상태를 복구하며, 준비 중에는 참가자의 재접속을 기다립니다. 중단된 월드 복원은 다음 실행에서 다시 시도합니다.
- 손상된 세션 파일을 보존하고 새 게임이 덮어쓰지 않도록 차단합니다. 애드온의 커스텀 게임 모드는 자체 복구 구현이 필요하며, 실행 중인 임시 능력 효과는 자동 재생하지 않습니다.

## 검증 및 설치

- `clean build`, 단위 테스트 39개와 배포 JAR의 Java 8 바이트코드·테스트 플러그인 미포함 검사를 통과했습니다.
- Paper 26.3에서 정상 재시작·강제 종료·준비 중 복구·월드 복원 중단·손상 세션 보존을 포함한 6단계 복구 검사와 월드 메타데이터 무결성 검사를 통과했습니다. 월드 저장 수정 후 Paper 26.2의 코어·월드 복원 검사도 통과했습니다.
- 릴리즈는 최신 Paper 기동 및 코어·능력·명령어·복구 검사 성공 후 자동 게시됩니다. 전체 구버전 매트릭스는 기존 정책대로 별도 호환성 검사로 실행합니다.
- 자동 검사에는 실제 다인전 플레이와 클라이언트 화면의 시각 검증이 포함되지 않습니다.
- 서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.2.jar`로 교체한 뒤 재시작하세요. 기존 설정은 유지할 수 있으며, 복구 데이터는 `game-session.yml`과 `world-snapshots`를 함께 보관하세요.
