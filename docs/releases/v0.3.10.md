# NewGodWar v0.3.10

능력별 동작과 효과음을 개선하고, 한글 설정 메뉴와 도박 화면을 정리했습니다.

## 주요 변경

- 시전자의 동작과 대상의 피격·회복·상태 반응을 분리하고, 실제 피해·회복 판정에 맞춰 연출합니다.
- 주작·헤르메스·니케의 날개와 의술 지팡이·약탕·난초·삼지창 등 능력별 모델 및 애니메이션을 개선했습니다.
- 발동·제작·지속·종료 효과음을 사건별로 연결하고, 중복 소리와 은신 중 소리 노출을 줄였습니다.
- 능력 배정·중간 참여 등 안내를 액션바로 정리하고, 간결한 전투 메시지 설정을 추가했습니다.
- 설정 홈과 하위 메뉴에 한글 배경·버튼을 적용하고, 도박 화면에서 잔액·비용·결과와 보상 목록을 확인하기 쉽게 개선했습니다.
- 연습용 더미와 관련 명령·회귀 검사를 보강하고 능력별 연출 설계표를 추가했습니다.

## 리소스팩

통합 팩 `NewGodWar-Art-d36217f4.zip`을 사용합니다. 팩은 [resoucepack 디렉토리](https://github.com/minjae9010/NewGodWar/tree/master/resoucepack)에서 제공하며 플러그인 JAR에는 포함하지 않습니다. Minecraft 1.14~26.3에서 팩을 사용하고 1.12~1.13에서는 기본 아이템과 파티클로 표시합니다.

## 설치

서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.10.jar`로 교체한 뒤 재시작하세요. 자동 리소스팩은 `abilities.effects.resource-pack.enabled: true`, `url: 'auto'`, `sha1: ''`로 설정하고 클라이언트에서 다운로드를 수락하세요.

검사 범위와 실제 클라이언트 화면 검증의 한계는 [테스트 문서](https://github.com/minjae9010/NewGodWar/blob/v0.3.10/docs/testing.md)를 참고하세요.
