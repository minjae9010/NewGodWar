# NewGodWar v0.3.12

능력 10종의 전투 흐름을 개선하고, 주기 저장 지연과 재접속·구버전 메뉴 문제를 수정했습니다.

## 능력 변경

- 메구밍은 폭렬과 자폭 후 90초가 지나면 다시 사용할 수 있으며, 우클릭 충전으로 남은 시간을 줄입니다. 기존 저장의 사용 완료 상태도 재사용 대기로 전환합니다.
- 포켓몬고는 서로 다른 4×4블록 구역 16곳을 탐험하면 새 능력을 얻습니다. 같은 구역 왕복은 진도에 포함하지 않으며 탐험 기록을 저장합니다.
- 허준·세종대왕·이순신의 일반기를 25~30초마다 사용할 수 있는 치료·지원·진입 기술로 조정했습니다.
- 정원사는 꽃을 건설용 목재로 교환하고, 신사임당은 아군에게 난초 보호막을 제공합니다.
- 사이코스노우는 실제 눈덩이 적중으로 성장하며, 금수저는 시작 장비와 주기적인 무료 보급을 받습니다.
- 수험생은 짧은 산수 문제를 풀며, 오답에도 같은 문제에 추가 비용 없이 다시 답할 수 있습니다.

비용·쿨타임·성장 조건은 [능력 목록](https://github.com/minjae9010/NewGodWar/blob/v0.3.12/docs/wiki/abilities.md)에서 확인하세요.

## 저장 성능과 안정성

- 지원되는 최신 서버에서는 플레이어 데이터를 서버 스레드에서 캡처한 뒤 압축·파일 쓰기를 최대 8개 작업 스레드로 처리합니다. 모든 저장이 끝난 뒤 같은 틱에서 월드와 세션을 확정합니다.
- 플레이어 파일의 원자 교체와 백업을 유지하고, 내용이 같은 통계·발전과제 JSON의 쓰기를 생략합니다. 저장 실패 시 이전 세션을 유지하며, 지원되지 않는 서버는 기존 Bukkit 저장 경로를 사용합니다.
- 재접속한 플레이어의 팀 표시를 다른 플레이어의 스코어보드에도 반영합니다. 반복 갱신은 필요한 사이드바만 갱신하고 만료된 피해 추적 정보를 정리합니다.
- 능력의 공동 콜백 오류가 다른 플레이어의 능력 실행을 중단하지 않도록 격리하고, 같은 능력 세션의 오류 로그를 30초 간격으로 제한합니다.
- Paper 1.12.2 등의 인벤토리 래퍼에서도 뽑기 메뉴가 동작하며, 이전 메뉴의 지연 클릭과 닫기 이벤트가 새 메뉴를 변경하지 않도록 검사합니다.
- 선택적 저장 시간 진단 설정 `game.log-save-timings`를 추가했습니다. 기본값은 `false`입니다.

동일 실행 코드로 진행한 로컬 Paper 26.3·32명·모드별 60초 검사에서 최대 틱은 일반 287.76→193.65ms, 우르프 286.92→181.29ms로 줄었고, 기존 성능 기준과 실제 접속자 강제 종료 복구 검사를 통과했습니다. 환경별 성능이나 수용 인원을 보장하는 수치는 아닙니다. 측정 조건과 원본 기록은 [테스트 문서](https://github.com/minjae9010/NewGodWar/blob/v0.3.12/docs/testing.md)를 참고하세요.
