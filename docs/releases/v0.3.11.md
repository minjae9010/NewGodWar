# NewGodWar v0.3.11

능력의 입체 모델을 개선하고, 투척·회수·수직 시선에서 발생하던 움직임 오류를 수정했습니다.

## 주요 변경

- 묠니르·궁니르·삼지창·단검·방패를 두께가 있는 3D 모델로 제작해 10개 연출에 연결했습니다.
- 묠니르는 머리가 앞서는 자세로 날아가고, 그 자세를 유지하면서 손잡이부터 시전자의 손으로 돌아옵니다. 시전자가 이동하거나 시점을 바꿔도 회수 자세를 뒤집지 않습니다.
- 궁니르는 오른손 앞에서 출발해 움직이는 표적을 향해 0.6초 동안 날아갑니다. 기존 비용·피해·적중 시점과 엄폐 판정을 유지합니다.
- 니케 돌진·아테나 진형·암살자 뒤잡기와 공통 밀쳐내기가 수직 시선에서도 원래 수평 방향을 유지합니다.
- 근거리 투척의 출발점이 표적을 지나치지 않도록 제한하고, 삼지창 방향·낚싯바늘 전진/회수·태양 화살의 기본 발사 방향을 수정했습니다.
- 날개와 카메라를 향하는 잔상의 위치를 안정화하고, 로드되지 않은 청크에서 효과가 정리된 뒤 다음 효과가 다시 표시되도록 수정했습니다.
- 같은 위치·모양·아이템을 반복 갱신하지 않도록 최적화하고, 모델 재사용과 만료 시 정리를 보강했습니다.

## 리소스팩

통합 팩 [NewGodWar-Art-b2d524b9.zip](https://raw.githubusercontent.com/minjae9010/NewGodWar/master/resoucepack/NewGodWar-Art-b2d524b9.zip)을 사용합니다. SHA-1은 `b2d524b99e694910f993b7633033aa7d230696d9`입니다. 기존 모델 ID 1,957개를 유지하고 미사용 평면 이미지 40개를 작은 재질 아틀라스로 대체했습니다. ZIP은 플러그인 JAR와 별도로 제공합니다.

## 설치와 검사

서버를 종료하고 기존 JAR를 `NewGodWar-0.3.11.jar`로 교체한 뒤 재시작하세요. 자동 리소스팩은 `abilities.effects.resource-pack.enabled: true`, `url: 'auto'`, `sha1: ''`로 설정합니다. 직접 팩 주소를 사용하는 서버는 위 ZIP과 SHA-1을 함께 갱신하세요.

단위 테스트 127개와 Paper 1.12.2·26.3 능력 회귀 검사를 통과했습니다. 실제 Minecraft 26.3에서 93개 능력의 사용 가능한 일반/고급 기술을 순회하고, 수정본의 방향·투척·취소·공중 비행·150개 모델 재생과 소멸을 추가 확인했습니다. 최종 시각 검사에는 187개 영상·7,677개 원본 프레임을 사용했습니다. 패시브·특수 조건의 서버 재현과 실제 클라이언트 입력은 구분하며, 모든 환경의 시각 결과를 보장하는 검사는 아닙니다. 상세 범위는 [테스트 문서](https://github.com/minjae9010/NewGodWar/blob/v0.3.11/docs/testing.md)를 참고하세요.
