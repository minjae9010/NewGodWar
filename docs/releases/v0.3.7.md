# NewGodWar v0.3.7

리소스팩 배포를 플러그인 릴리즈에서 분리했습니다.

- 버전별 ZIP 25종을 [같은 저장소의 리소스팩 전용 공간](https://github.com/minjae9010/NewGodWar/tree/codex/resource-packs)에 보관합니다. `url: auto`는 해당 공간의 GitHub Raw 고정 주소를 사용합니다.
- 플러그인 빌드와 릴리즈에서 리소스팩 생성·업로드를 제거했습니다. 게시된 버전 목록과 SHA-1만 포함하며, 이번 릴리즈에는 플러그인 JAR만 첨부합니다.
- 팩 내용이 바뀔 때만 별도로 생성·게시합니다. 기존 해시 경로를 유지하므로 이미 설치한 플러그인도 같은 파일을 계속 사용할 수 있습니다.

서버를 종료하고 JAR를 교체한 뒤 재시작하세요. `abilities.effects.resource-pack.url: auto`는 새 공간을 자동 사용합니다. 기존 릴리즈 ZIP 주소를 직접 입력했다면 `auto`로 바꾸세요. [팩 설정과 직접 다운로드](https://github.com/minjae9010/NewGodWar/wiki/resource-packs)를 참고하세요.
