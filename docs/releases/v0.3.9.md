# NewGodWar v0.3.9

능력 연출과 메뉴·음식 모델을 개선하고, 여러 마인크래프트 버전에서 함께 사용하는 통합 리소스팩을 제공합니다.

## 주요 변경

- 능력 문양에 기 모으기·섬광·충격파·여운 애니메이션을 추가하고 제작·요리·경제 능력의 전용 장면을 보강했습니다.
- 메뉴 아이콘과 식신의 여섯 요리 모델, 능력 설명과 안내 문구를 개선했습니다.
- 사이코스노우의 공격 지수를 세션에 저장·복구하고 사망 시 증가 안내를 표시합니다.
- 접속 종료 시 설정 메뉴와 팀 이름 변경 대기 상태를 정리합니다.
- bStats 플러그인 식별자를 갱신했습니다.

## 리소스팩

통합 팩 `NewGodWar-Art-28ac15d7.zip`은 Minecraft 1.14~26.3의 구형·신형 아이템 모델 방식을 함께 지원합니다. 파일명에 SHA-1 일부를 사용하며 이전 릴리스의 팩은 그대로 보관합니다. 팩은 [resoucepack 디렉토리](https://github.com/minjae9010/NewGodWar/tree/master/resoucepack)에서 별도로 제공하며 플러그인 JAR에는 포함하지 않습니다.

`abilities.effects.resource-pack.url: 'auto'`로 새 팩을 적용합니다. Minecraft 1.12~1.13에서는 기본 아이템과 파티클을 사용합니다. [리소스팩 안내](https://github.com/minjae9010/NewGodWar/blob/v0.3.9/docs/wiki/resource-packs.md)에서 상세 지원 범위를 확인하세요.

## 설치

서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.9.jar`로 교체한 뒤 재시작하세요. 자동 리소스팩을 사용하려면 `abilities.effects.resource-pack.enabled: true`, `url: 'auto'`, `sha1: ''`로 설정하고 클라이언트에서 다운로드를 수락하세요.
