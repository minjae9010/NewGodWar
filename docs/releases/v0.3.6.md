# NewGodWar v0.3.6

메뉴·능력·식신 음식 아트와 지금까지의 능력 및 UI 개선을 배포하고, 리소스팩을 Minecraft 버전별로 자동 연결합니다.

- 메뉴 31종, 식신 음식 6종, 97개 시각 모델의 아트를 버전별 팩으로 제공합니다. 설정 홈·도박·능력 도감의 안내와 조작을 개선했습니다.
- 72개 능력의 행동별 디자인과 애니메이션, 대상·범위 처리, 식신 음식 공유, 하데스 월드 최저 높이 처리 등을 개선했습니다.
- 리소스팩 ZIP 25종과 SHA-1, 54개 버전 목록을 이 GitHub Release에 첨부합니다. `abilities.effects.resource-pack.url: auto`로 서버 버전에 맞는 주소와 해시를 자동 선택합니다. 기존 빈 URL도 자동 선택하며 전송을 끄려면 `enabled: false`로 설정합니다.
- 1.14~1.21.3은 CustomModelData/overrides, 1.21.4 이상은 새 item definition을 사용합니다. 1.21.11 이후 아이템 아틀라스와 1.21.9 이후 팩 메타데이터 변경도 반영합니다.
- 1.12~1.13은 기본 아이템·파티클을 유지하고 팩을 자동 전송하지 않습니다. Display 문양은 1.19.4 이상에서 제공됩니다. 자동 선택은 서버 버전 기준이며 ViaVersion의 서로 다른 클라이언트별 선택은 지원하지 않습니다.

[다운로드별 지원 버전과 설정](https://github.com/minjae9010/NewGodWar/blob/v0.3.6/docs/wiki/resource-packs.md)을 확인하세요. ZIP 파일을 풀지 않고 사용합니다. 플러그인 업데이트는 서버를 종료한 뒤 기존 JAR를 `NewGodWar-0.3.6.jar`로 교체하고 재시작합니다.

JDK 21 빌드·단위 테스트 76개, 전체 ZIP 구조·해시·모델 검사 및 actionlint를 통과했습니다. 서버 회귀와 실제 클라이언트 화면 검증 범위는 [테스트 안내](https://github.com/minjae9010/NewGodWar/blob/v0.3.6/docs/testing.md)에 구분되어 있습니다. 릴리즈 게시 전 최신 Paper 기동·코어·능력·명령·복구 검사를 GitHub Actions에서 수행합니다.
