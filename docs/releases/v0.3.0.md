# NewGodWar v0.3.0

## 애드온과 게임 모드

- `plugins/NewGodWar/addon/`에 Bukkit 애드온 JAR를 넣고 서버를 재시작하면 자동 로드됩니다.
- 능력 등록 API, 게임 상태 이벤트, 애드온 비활성화 시 등록·배정 정리를 추가했습니다.
- `game.mode`로 애드온의 게임 모드를 선택할 수 있습니다. 기본값 `default`는 기존 코어전입니다.
- 전체 교체 모드는 시작·전투·승리 조건과 종료 정리를 직접 구현할 수 있습니다.
- 능력 및 60초 자유 게임 예제를 `examples/addon`에 추가했습니다.

## 상자 GUI

- 설정을 6줄로 확장하고 카테고리와 하단 탐색 버튼을 분리했습니다.
- 능력 도감에 7열 배치와 등급별 아이콘을 적용했습니다.
- 카지노의 뽑기 버튼, 비용 안내, 닫기 버튼을 분리했습니다.
- 공통 테두리와 상태 표시를 정리하고 가려지던 킬타임 방식 버튼을 복구했습니다.

## 최적화와 검증

- 스코어보드는 변경된 줄만 갱신하며 다른 목적의 점수는 보존합니다.
- 능력 추첨 중 블랙리스트를 반복해서 읽는 작업을 줄였습니다.
- 테스트 18개와 로컬 Paper 26.2의 애드온 로딩, 교체 모드 시작·종료, 설정·능력 GUI 생성 검증을 통과했습니다.
- 실제 다인전 플레이와 클라이언트 화면의 시각 검증은 별도로 필요합니다.

## 설치

서버를 종료한 뒤 기존 본체 JAR를 `NewGodWar-0.3.0.jar`로 교체하고 재시작하세요. 애드온은 본체와 별도로 `plugins/NewGodWar/addon/`에 설치합니다. 애드온 제작 방법은 저장소의 `docs/wiki/addon-development.md`를 참고하세요.
