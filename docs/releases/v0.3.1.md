# NewGodWar v0.3.1

게임 코어의 탈락·승패 처리와 시작 검사를 수정하고, GUI에서 준비 및 능력 사용법을 더 쉽게 확인하도록 개선했습니다.

## 게임 코어 수정

- 팀 미배정·관전자·탈락 팀·비활성 팀 플레이어의 심장 파괴를 차단합니다.
- 하나의 폭발로 여러 심장이 파괴되면 모든 팀의 탈락을 먼저 반영하고 승패를 한 번만 판정합니다. 마지막 팀들이 함께 탈락하면 무승부로 종료합니다.
- 같은 블록을 다른 팀의 심장으로 중복 등록할 수 없습니다. 기존 설정 파일에 남은 중복도 게임 시작 검사에서 안내합니다.
- 준비 카운트다운 종료 시 최소 참가 인원과 스폰·심장 설정을 다시 확인합니다. 조건 미충족 시 준비를 취소하고 예약 작업을 정리합니다.

## GUI와 능력 안내

- 시작 준비 체크리스트와 종료 확인·취소 화면을 추가했습니다.
- 능력 도감에 검색 버튼, 일반·고급·패시브 상세 화면, 검색·페이지를 유지하는 돌아가기를 추가했습니다. 검색 버튼을 누른 뒤 채팅으로 검색어를 입력합니다.
- 능력별 도구·좌우클릭·대상 지정·특수 조작법을 명시하고 긴 한국어 설명에 자동 줄바꿈을 적용했습니다.
- 내 능력 화면에 재료 부족·봉인 상태와 상태 새로고침을 추가했습니다. 스크루지 재료 할인 및 우르프 적용 쿨타임을 표시합니다.
- 내장 능력 90개의 Wiki 설명과 기본 수치를 코드에 맞췄습니다.

## 검증 및 설치

- 빌드·단위 테스트 외에 실제 Paper 서버의 코어 회귀 테스트를 릴리즈 필수 검사로 추가했습니다.
- 서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.1.jar`로 교체한 뒤 재시작하세요. 기존 설정은 유지할 수 있습니다.
- 무승부 문구는 `messages.draw`에서 설정할 수 있습니다. 해당 항목이 없어도 기본 문구가 사용됩니다.
