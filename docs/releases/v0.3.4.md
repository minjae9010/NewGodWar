# NewGodWar v0.3.4

93종 능력의 연출을 실제 행동에 맞게 정리하고, 지원 서버의 입체 오브젝트 이펙트와 플레이어형 테스트 더미를 추가했습니다. 명령어 도움말과 일회용 능력의 사용 상태도 개선했습니다.

## 능력 이펙트

- 묠니르·궁니르·방패·날개·룬·심판 저울·중력핵을 Display 오브젝트로 표현합니다. 별도 리소스 팩은 필요하지 않습니다.
- Display API가 없거나 오브젝트 예산을 초과하면 같은 형태의 파티클로 자동 전환합니다. 장면 갱신 시 엔티티를 재사용하고, 만료·사망·로그아웃·능력 해제 때 정리합니다.
- 회복은 대상의 하트, 속박은 발목의 뿌리, 수면은 머리 위 표시처럼 효과가 일어난 위치에 연출합니다. 전용 연출과 공통 장식의 중복을 줄이고 투사체 궤적과 비행 잔상을 추가했습니다.
- 표시 거리·은신·개별 가시성과 파티클·오브젝트 수 제한을 적용합니다. `abilities.effects.objects`, `object-limit`, `animations` 설정으로 조정할 수 있습니다.
- 자세한 설정과 능력별 표현은 [능력 이펙트 안내](https://github.com/minjae9010/NewGodWar/blob/v0.3.4/docs/wiki/ability-effects.md)를 확인하세요.

## 도움말과 테스트 더미

- `/gw`와 `/gw help`에서 자주 쓰는 명령을 바로 보여주며, 유저 명령과 관리자 전용 명령을 구분합니다. 분류별 도움말·검색·페이지 이동·별칭과 자동완성은 계속 지원합니다.
- 관리자는 `/gw test <능력>`과 `/gw dummy`로 플레이어형 타깃 더미를 소환해 능력을 시험할 수 있습니다. `/x` 대상 지정과 시선·범위 공격을 지원하며 `/gw dummy remove`로 제거합니다.
- 더미는 참가 인원·자동 팀 배정·킬 점수에 포함되지 않습니다. 체력을 회복하며 소환자 로그아웃·월드 이동·게임 종료 시 정리됩니다.

## 사용 상태와 동작 수정

- 이미 소비한 일회용 능력은 능력 GUI와 상태 표시에 `사용 완료 · 재사용 불가`로 표시합니다. 쿨타임 초기화로 일회용 능력이 복구되지 않습니다.
- 스나이퍼의 준비가 끝나기 전에 강화 화살을 발사할 수 없도록 수정하고 사망·능력 해제 시 준비 상태를 정리합니다.
- 타짜가 검 없이 비용을 소비하지 않도록 하고, 이름·인챈트 등 메타데이터가 있는 검도 정확히 한 개 소비합니다.
- 블록 폭발 콜백에 능력 컨텍스트를 추가하면서 기존 애드온 콜백과의 호환성을 유지합니다.

## 검증과 설치

- JDK 21의 `clean build`, 단위 테스트 48개와 배포 JAR의 Java 8 바이트코드·테스트 전용 클래스 제외를 확인했습니다.
- Paper 1.12.2·26.3에서 능력·명령어·더미 회귀 검사를 통과했습니다. 93종 연출, Display 모델 10종과 파티클 폴백, 가시성·생성 실패·예산·정리, 일회용 상태, 명령 권한과 더미 수명주기를 검사합니다.
- 자동 릴리스는 최신 지원 Paper 기동과 코어·능력·명령어·서버 복구 검사를 통과한 뒤 게시됩니다. 클라이언트 화면과 실제 다인전 밸런스는 자동 검사 범위에 포함되지 않습니다.
- 서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.4.jar`로 교체한 뒤 재시작하세요. 기존 설정은 유지할 수 있습니다.
