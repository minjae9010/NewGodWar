# NewGodWar v0.3.8

능력 연출·메뉴·식신 음식 개선을 포함하고, 버전별 리소스팩을 같은 저장소의 `resoucepack/` 경로에서 다운로드하도록 제공합니다.

## 리소스팩 다운로드

- 리소스팩 ZIP 25종과 SHA-1은 [resoucepack 디렉토리](https://github.com/minjae9010/NewGodWar/tree/master/resoucepack)에 보관합니다. 플러그인 릴리즈에는 JAR만 첨부하며, 플러그인을 빌드하거나 릴리즈할 때 기존 팩을 다시 생성하지 않습니다.
- `abilities.effects.resource-pack.url: 'auto'`를 사용하면 서버 버전에 맞는 GitHub Raw 주소와 SHA-1을 선택합니다. JAR에는 파일명·해시·모델 목록만 들어갑니다.
- Minecraft 1.14 이상에서 전용 메뉴와 음식 모델, 1.19.4 이상에서 ItemDisplay 연출을 사용합니다. 1.12~1.13은 팩을 자동 제안하지 않고 기본 아이템과 파티클을 사용합니다. 자동 선택은 서버 버전 기준입니다.
- 버전별 주소와 지원 범위는 [리소스팩 안내](https://github.com/minjae9010/NewGodWar/blob/v0.3.8/docs/wiki/resource-packs.md)를 참고하세요.

## 게임과 화면 개선

- 능력별 행동 연출과 문양을 추가하고, 능력·설정·도박 메뉴의 배치와 설명 및 명령어 도움말을 개선했습니다.
- 식신의 전용 음식 6종과 모델·사용 처리를 추가했습니다.
- 능력의 대상·범위 판정과 하데스의 월드 최저 높이 처리를 보완했습니다.

## 설치

서버를 종료하고 기존 플러그인 JAR를 `NewGodWar-0.3.8.jar`로 교체한 뒤 재시작하세요. 기존 설정에 직접 지정한 리소스팩 URL이 있으면 `abilities.effects.resource-pack.enabled: true`, `url: 'auto'`, `sha1: ''`로 변경하면 버전별 자동 다운로드를 사용합니다. 클라이언트에서 리소스팩 다운로드를 수락해야 전용 모델이 표시됩니다.
