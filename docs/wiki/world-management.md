# 월드 관리

NewGodWar는 로비 월드와 게임 월드를 분리해서 운영할 수 있습니다. 게임 월드를 지정하면 일반 게임(`/gw start`)과 능력 테스트(`/gw test`) 시작 직전에 스냅샷을 만들고, 게임 종료 후 로비로 플레이어를 돌린 다음 게임 월드를 복원합니다.

복원 기준은 해당 게임이나 테스트를 시작하기 직전의 맵입니다. 시작 전에 이미 있던 상자나 건축물은 유지됩니다. 이전 버전의 능력 테스트에서 남은 블록이 있다면 `/gw stop` 후 대기 상태에서 정리하고 다음 게임을 시작하세요.

## 빠른 사용법

| 목적 | 방법 |
| --- | --- |
| 월드 도움말 확인 | `/gw world help` 또는 `/gw help world` |
| 월드 목록 확인 | `/gw world list` |
| 현재 위치를 로비로 저장 | `/gw setlobby` |
| 게임 맵 선택 | `/gw map <world>` |
| 게임 맵 선택 해제 | `/gw map clear` |
| 월드 설정 GUI 열기 | `/gw world gui` |
| 전체 설정 GUI 열기 | `/gw gui` 또는 `/gw settings` |

`/gw map <world>`는 로드된 월드를 선택합니다. 월드 폴더만 있고 아직 로드되지 않은 경우에는 자동으로 로드한 뒤 선택합니다. 선택된 맵의 팀 스폰과 심장은 `maps.<world>` 아래에 별도로 저장되므로, 새 맵을 만들면 해당 맵에서 `/gw setspawn <team>`과 `/gw settemple <team>`을 다시 지정하세요.

기존 서버에서 `world.game-world`와 `spawns`, `temples`를 이미 사용 중이었다면 그대로 둬도 됩니다. 기존 위치의 월드명이 선택된 게임 맵과 같으면 플러그인이 시작/리로드 시 `maps.<world>` 아래로 자동 복사합니다.

설정 GUI에서는 `월드` 메뉴를 열어 자동 저장, 동물/몬스터 스폰, 시작 시간, 시작 난이도, 게임 월드 자동 초기화, 현재 월드를 게임 월드로 지정/해제를 조정할 수 있습니다.

## GUI 설정

1. 관리자로 접속하고 `/gw world gui`를 실행합니다.
2. 필요한 항목을 클릭해 값을 바꿉니다.
3. 게임 월드로 쓸 월드에 서서 `현재 월드를 게임 월드로 지정`을 클릭합니다.
4. 자동 초기화를 끄고 싶으면 `게임 월드 자동 초기화`를 꺼둡니다.

전체 설정 GUI에서 들어가려면 `/gw gui`를 실행한 뒤 `월드` 메뉴를 클릭합니다.

`게임 시작 월드 시간` 항목은 클릭하면 현재 월드 시간을 저장합니다. 좌우의 시간 버튼은 1000틱 단위, Shift 클릭은 6000틱 단위로 조정합니다. 난이도는 `PEACEFUL`, `EASY`, `NORMAL`, `HARD` 순서로 순환합니다.

## 월드 생성과 로드

| 명령어 | 설명 |
| --- | --- |
| `/gw world create <world> [normal\|flat\|void]` | 새 월드를 생성하고 로드합니다. |
| `/gw world load <world> [normal\|flat\|void]` | 서버 폴더에 있는 월드를 로드하고 자동 로드 목록에 등록합니다. |
| `/gw world copy <sourceWorld> <newWorld> [normal\|flat\|void]` | 기존 월드 폴더를 복사해 새 월드로 로드합니다. |

`void` 타입은 공허 월드 생성용입니다. `normal`, `flat`, `void`를 생략하면 일반 월드로 처리되거나 저장된 관리 월드 타입을 사용합니다.

## 이동과 정리

| 명령어 | 설명 |
| --- | --- |
| `/gw world tp <world> [player]` | 자신 또는 지정 플레이어를 해당 월드 스폰으로 이동합니다. |
| `/gw world lobby [player]` | 저장된 로비 위치로 이동합니다. |
| `/gw world unload <world> [save]` | 플레이어가 없는 월드를 언로드합니다. 기본값은 저장입니다. |
| `/gw world delete <world> confirm` | 플레이어가 없는 월드를 언로드하고 월드 폴더를 삭제합니다. |

기본 월드와 로비 월드는 보호 대상이라 언로드/삭제할 수 없습니다. 삭제는 되돌릴 수 없으므로 먼저 백업을 만드는 것을 권장합니다.

## 백업과 복원

| 명령어 | 설명 |
| --- | --- |
| `/gw world backup create [이름]` | 현재 로드된 모든 월드를 `plugins/NewGodWar/world-backups/`에 백업합니다. |
| `/gw world backup list` | 저장된 백업 목록을 확인합니다. |
| `/gw world backup load <백업이름> [로드월드이름]` | 백업의 모든 월드를 새 폴더로 복사해 로드합니다. |

백업 로드는 기존 월드에 직접 덮어쓰지 않습니다. 백업에 월드가 하나면 지정한 이름을 그대로 사용하고, 여러 개면 `<로드월드이름>-<원본월드명>`으로 각각 생성합니다. 이름을 생략하면 `ngw-<백업이름>`을 기준으로 같은 규칙을 적용합니다.

예를 들어 `/gw world backup load arena-1 reset-arena`를 실행할 때 `arena-1` 백업에 월드가 하나만 있으면 `reset-arena`로 로드합니다. `world`, `world_nether`, `world_the_end`가 들어 있으면 `reset-arena-world`, `reset-arena-world_nether`, `reset-arena-world_the_end`로 모두 로드합니다. 이동하거나 게임 맵으로 지정할 때는 `/gw world list`에서 실제 생성된 이름을 확인하세요.

## 운영 주의사항

### 서버 종료와 게임 복구

기본 게임은 서버 종료를 `/gw stop`과 구분합니다. 서버가 꺼져도 참가자의 인벤토리를 비우거나 로비로 보내지 않으며, 다음 실행에서 저장된 게임을 이어갑니다. 팀, 능력 배정과 기본 쿨타임, 탈락 상태, 킬 수, 관전자, 재추첨 횟수, 경과 시간, 시작 전 맵 스냅샷 정보를 `plugins/NewGodWar/game-session.yml`에 저장합니다. 서버가 꺼져 있던 시간은 게임 경과 시간에 포함하지 않습니다.

- 진행 상태와 월드/플레이어 데이터는 기본 10초 간격으로 저장합니다. `game.recovery-save-interval-seconds`로 조정할 수 있습니다. 큰 월드에서는 저장 간격을 너무 짧게 잡지 마세요.
- 주요 게임 변경과 정상 서버 종료 때도 진행 상태를 저장합니다. 프로세스 강제 종료나 정전 때는 마지막으로 디스크에 저장된 데이터까지 복구되며, 저장 이후의 변경은 유실될 수 있습니다.
- 준비 중 종료됐다면 기존 참가자가 재접속할 때까지 카운트다운을 기다립니다. 관리자는 `/gw skip`으로 대기를 해제할 수 있습니다. 최소 인원 등 기존 시작 조건은 유지됩니다.
- `/gw stop` 또는 승리로 게임이 종료될 때 시작 전 맵으로 복원합니다. 복원 실패나 복원 도중 종료가 발생하면 스냅샷 정보를 보존하고 다음 실행에서 다시 시도합니다. 실패한 스냅샷 위에 다음 게임 맵을 덮어쓰지 않습니다.
- 저장 파일이 손상됐거나 필요한 월드·능력·팀이 없으면 복구를 중단하고 원본 파일을 유지합니다. 로그에 표시된 원인을 해결한 뒤 다시 실행하세요. `game-session.yml`과 `world-snapshots`는 함께 보관해야 합니다.

자동 이어하기는 기본 게임과 능력 테스트에 적용됩니다. 애드온이 게임 전체를 대체하는 커스텀 모드는 자체 복구 구현이 필요합니다. 능력의 실행 중 임시 효과와 개별 능력 내부 상태는 자동 재생하지 않으며, 애드온 능력은 `GodAbility.saveSession/loadSession`으로 추가 상태를 저장할 수 있습니다. 이 기능을 설치하기 전에 이미 유실된 게임 상태는 되살릴 수 없습니다.

- 로비 월드는 게임 월드로 지정할 수 없습니다.
- 맵마다 팀 스폰과 심장을 따로 설정해야 합니다.
- 게임 월드 자동 초기화는 로비 위치가 있어야 안전하게 동작합니다.
- 게임 종료 시 게임 월드에 플레이어가 남아 있으면 안전을 위해 복원을 건너뛸 수 있습니다.
- 월드를 삭제하거나 언로드하기 전에는 `/gw world lobby [player]` 또는 `/gw world tp <world> [player]`로 플레이어를 다른 월드로 이동하세요.
