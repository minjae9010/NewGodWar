# 능력별 이펙트·효과음 설계표

2026-10-03. 실제 AbilityInfo, STYLE 연결, 행동별 모델에 대응하는 구현 안내. 수치·판정·비용은 변경하지 않는다.

## 공통 사건 규칙

- 성공 발동: 시각 효과가 NONE인 전용 능력도 일반/고급마다 확인음 1회. 일반 음량 0.36·음높이 1.15, 고급 0.52·0.85. 번개는 실제 천둥과 겹치지 않는 전하/플링 소리.
- 역할 분리: 시전자의 의술 지팡이·약탕·마법책·삼지창과 대상의 회복·중독·물보라·피격을 별도로 연결한다. 대상의 충돌 반응은 시선이 아니라 공격이 들어온 방향을 유지한다. `STYLE.received`는 뿌리·봉인·부두 인형처럼 대상에 붙어야 하는 모델만 명시한다.
- 실제 판정: 저격수는 준비 완료 조준경, 실제 발사 순간 짧은 섬광, 강화 화살의 최종 피해 확인 후 대상의 작은 탄착으로 구분한다. 일반 화살·취소·피해 0·후속 취소·능력 제거에는 명중 연출이 없다. 허공의 가짜 탄착과 피격자 조준경을 제거했다. 아처·아레스·광부·타짜·원펀치·세종의 공격 반응도 최종 피해를 확인한다. 상태 알림 문구 자체는 적용 판정으로 사용하지 않는다.
- 상태 반응: 독은 몸 안쪽으로 모이는 작은 독빛, 감속은 발목 사슬, 봉인은 몸 주위 결속, 실명은 눈앞의 작은 가림, 수면·음악은 머리 주변 표식. 대상에게 시전용 원형 마법진·원거리 빛기둥을 붙이지 않는다. 완전 회복은 실제 체력 증가를 확인한 뒤 대상 반응을 낸다.
- 대상 반응: 상태·피격·치유 사건을 한 번 합친 후 반응음. 시전자 자신의 즉시 반응은 발동음과 중복하지 않는다. 광역 반응은 청취자별 100ms 묶음으로 중첩을 제한한다.
- 제작: 발동 시 모루 놓기, 1·4·7틱 망치 접촉 시 단조음. 파티클 대체 모델도 같은 타이밍. 예약 소리는 세션 종료·사망·월드 변경 시 취소한다.
- 지속: 비행 날갯짓, 시계의 박자, 수확 단계, 피리 음표처럼 실제 유지되는 사건에만 소리를 붙인다. 무관한 능력 전체에 반복음을 추가하지 않는다.
- 종료: laterCleanup으로 관리하는 실제 효과 종료 및 비행 착지에 낮고 짧은 종료음. 단순 장식의 18틱 소멸은 기술 종료로 취급하지 않는다.
- 비공개·은신: 발동 전에도 privateCast 정책을 적용한다. 멀거나 시전자를 볼 수 없는 관전자에게 소리를 보내지 않는다.
- 설정: sounds는 particles/objects/animations와 독립. effects.enabled는 전체 OFF. 리소스팩 유무가 소리를 결정하지 않는다.

## 이번에 다시 만든 동작

- **jujak**: 등의 어깨깃 → 양쪽 6장 비행깃이 9틱 동안 전개 → 손목이 늦게 따라오는 날갯짓. 적금색 긴 꼬리깃 2장. 비행 중 약 1.1초 간격 낮은 날갯짓 소리, 착지·비행 종료 시 닫는 소리.
- **hermes**: 백금색 어깨깃과 짧은 덮깃. 주작과 같은 관절 구조를 쓰되 꼬리 길이·날갯짓 속도·음높이를 구분.
- **nike**: 돌진에 붙는 백금 날개와 처치로 쌓이는 월계관. 지속 비행음은 붙이지 않고 성공 발동과 착지 보호 사건을 구분.
- **asclepius**: 시전자 어깨 옆 의술 지팡이가 세워지고 빛점이 상승. 대상에게는 지팡이 대신 몸을 따라 오르는 작은 회복빛. 머리 위 표식은 작게, 전신 빛기둥은 제거.
- **heojun**: 시전자 허리 옆 약탕 그릇에 약초 3줄기가 돋고 온기가 상승. 대상은 회복·재생·보호 반응만 표시. 의술 지팡이와 다른 형태.
- **shinsaimdang**: 먹줄기가 먼저 그려지고 6틱부터 난초가 핀다. 마지막에는 꽃잎이 네 방향으로 흩어진다.
- **poseidon**: 삼지창이 2~6틱에 앞쪽으로 찔러 나가며 물결 3겹이 추진 방향을 따라 퍼짐. 교차 검격 제거.
- **zeus**: 위에서 아래로 순차 점등하는 5구간 번개와 발밑 전격 파편. 실제 낙뢰 소리는 게임 엔진에 맡기고 발동 확인은 작은 전하음.
- **quetzalcoatl**: 청록 깃털 10장이 몸을 나선으로 감으며 솟아오름. 일반 새 날개 대신 깃털 뱀의 윤곽.
- **voodoo**: 머리 위 작은 인형에 바늘 3개가 안쪽으로 꽂히고 인형이 짧게 떨림.
- **amaterasu**: 몸 옆 태양 거울을 돌려 앞쪽으로 빛을 반사. 태양 원반 소환과 구분.
- **ra**: 머리 위로 떠오르는 태양 원반에 6개의 방사광이 회전. 아마테라스의 손 거울과 구분.
- **apollon**: 태양 활·시위·화살을 별도 소품으로 분리. 0~4틱 당김, 4틱 발사, 앞쪽 짧은 잔광.
- **blacksmith**: 모루의 망치가 1·4·7틱에 내려치고 같은 박자에 단조음 3회. 완성 주괴/보석은 마지막에 나타남.
- **hephaestus**: 모루 단조와 담금질을 분리. 망치 타격음과 담금질의 치익 소리를 해당 동작에만 사용.

주문서는 접힌 양쪽 종이가 열리고 글자가 솟는다. 뿌리는 발목 높이까지 순차 성장한다. 술·차·가마솥은 손 옆 용기에서 증기가 오르고, 불꽃은 몸 주위에서 일렁인다. 큰 공통 섬광·빛기둥은 축소했다.

## 전체 93개 능력 실행 연결표

등록 목록 대신 실제 이벤트 함수에서 도달하는 연출을 추적했다. `scripts/audit-ability-presentation.py --check`로 93개 누락 여부와 연결되지 않은 시전 모델을 검사한다. 자세한 함수·행 번호는 `output/ability-redesign/ability-audit.json`에 남긴다. 이 정적 추적과 서버·클라이언트 실행 검증은 별개이며 검증 결과는 `output/ability-redesign/verification.json`에 기록한다.

준비 표시는 준비 사건, 공격 동작은 확인된 공격 사건, 수신 반응은 대상에게 실제 적용된 사건에서 실행한다. 강화·저주는 이미 유지 중인 효과보다 강하거나 새로 적용됐을 때 표시한다. 회복은 체력 증가, 수리는 장비 내구도 변경, 정화는 제거할 상태, 부양은 적용된 부양 효과, 봉인은 성공한 봉인 결과를 확인한다. 표시할 사건이 없는 정보 조회와 상시 면역에는 타격을 만들어 붙이지 않는다. 은신 시전은 본인에게만 표시한다.
