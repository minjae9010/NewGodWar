# 능력 이펙트 안내

93개 능력의 실제 행동에 맞춰 연출을 선택합니다. 제작·경제·탐험 능력도 만드는 물건과 행동(모루 단조, 제작대, 요리, 주식 차트, 할인 도장, 시험지, 나침반)을 그대로 보여줍니다. 일반·고급·패시브 실행 경로에 행동별 입체 디자인을 연결하고, 시계·까마귀·벌떼·폭탄·폭렬핵·나락 등 전용 장면을 보강했습니다. 치유도 의술 지팡이·약초·꽃·서약 고리처럼 능력별 형태와 움직임을 사용합니다. 수치 조회·할인처럼 별도 시각 행동이 없는 능력은 기존 안내를 유지합니다.

## 전용 동작 디자인

행동별 디자인은 약 0.9초 동안 **등장 → 동작 → 소멸**로 재생됩니다. 활은 시위를 당겼다 놓고, 단조 망치는 내려치며, 사슬은 자물쇠에 맞물리고, 공간 문은 접힙니다. 같은 행동의 공통 하트·연기·반짝임은 전용 디자인으로 대체해 중복하지 않습니다. 모든 성공 발동에 일반/고급 확인음을 붙이고, 실제 적용·타격·제작 접촉·종료 사건의 소리를 구분합니다. sounds 설정은 particles/objects 설정과 독립입니다.

각 능력의 `STYLE.effect(EffectCue, DesignedEffect)`에서 시전 동작을, `STYLE.received`에서 대상에 붙는 특수 반응을 선언합니다. 피격자는 무기·조준경·마법책을 시전하지 않으며 공격이 들어온 방향에서 작은 충돌 반응을 받습니다. [능력별 동작·효과음 설계표](ability-presentation-design.md)에 전체 93개 연결과 판정 규칙을 정리했습니다. 디자인 조립은 `AbilityDesigns`, 수명과 관전자 제어는 세션별 `AbilityFeedback`이 담당합니다. Display를 사용할 수 없어도 동일한 모델의 전체 조각에서 윤곽을 골고루 추출합니다.

## 빛의 문양 리소스팩

선택형 통합 팩 하나(1.14–26.3 공용)는 150개 모델 문양을 **빛으로 그린 연출**로 바꿉니다. 짧은 기술은 행동마다 다른 타이밍을 사용합니다. 주작 날개는 어깨에서 비행깃이 펼쳐지고, 약탕은 약초와 김이 오르며, 주문서는 페이지가 열리고 글자가 솟습니다. 큰 공통 섬광은 줄이고 주인공 소품의 형태와 동작이 먼저 보이게 합니다. 조준에는 발사·탄착을 넣지 않으며, 총·활의 명중 반응은 실제 피해가 확인된 대상에게만 표시합니다.

능력이 따로 꾸미지 않은 반응(감속·실명·신속·독·힘·회복·낮/밤·수리·정화·아이템 생성·은신·봉인·뿌리·불·서리·물·음악·수면·새싹·주문·허기·관문·검격·성급함·약화 27종)도 일반 파티클 대신 공용 애니메이션 디자인으로 표시합니다. 방패·날개는 기존 공용 모델을 사용합니다.

제작·경제 계열은 전용 장면을 사용합니다. 대장장이·헤파이토스는 모루를 세 번 두드리며 완성품(주괴·다이아몬드·검)을 꺼내고, 아처류는 3×3 제작대 칸이 차오른 뒤 결과물이 튀어나오며, 식신은 팬에서 요리가 완성되고, 나스닥은 실시간 차트(상승/폭락)와 금화 복제·파괴를 그립니다.

여기에 기술별 동작이 더해집니다. 참격은 앞쪽을 가르는 초승달 궤적, 주먹은 전방으로 퍼지는 충격 고리, 활·총은 시위 해제와 발사 지점의 짧은 잔광, 낙뢰는 하늘에서 깜박이며 떨어지는 빛기둥, 속박·저주는 안쪽으로 조여드는 충격파, 깃발·닻·인장은 위에서 떨어져 땅을 울리는 착지를 사용합니다.

### 프레임 애니메이션

그림 자체도 움직입니다. 두 방식을 함께 사용합니다.

- **한 번 재생 (서버가 프레임 선택, 초당 10프레임)**: 시전마다 처음부터 다시 재생됩니다.
  - 문양 그리기: 기를 모으는 동안 빛의 펜이 능력 문양의 획을 그어 나가고, 폭발 순간 완성된 문양이 나타납니다.
  - 폭발 6프레임: 섬광 → 충격 고리 확장 → 파편 비산 → 잔불.
  - 참격 6프레임: 칼날 끝의 별빛이 궤적을 긋고, 꼬리부터 사라집니다.
- **반복 재생 (클라이언트 `.mcmeta` 애니메이션, 프레임 사이 보간)**: 빛기둥 안에서 에너지 줄기가 위로 흐르고, 스파크가 반짝이며 돌고, 속성 파편이 살아 움직입니다. 불꽃은 일렁이고, 번개는 매 프레임 새로 갈라지며(보간 없이 끊어서), 잎은 팔랑이고, 깃털은 흔들리고, 결정에는 빛이 훑고 지나갑니다. 범위 링에는 테두리를 따라 도는 혜성 빛이 있습니다.

애니메이션 끄기(`abilities.effects.animations: false`)에서는 그리는 도중의 문양을 보여주지 않고 완성된 정지 형태를 표시합니다. 프레임 미리보기는 `build/effect-pack/animation-frames.png`입니다.

문양은 블러 기반 블룸·밝은 몸체·흰 심지의 세 겹으로 그려 낮에도 빛처럼 보입니다. 섬광·충격파·마법진·범위 링·빛기둥·스파크·참격·속성 파편 8종의 공용 레이어를 15개 속성 팔레트(금·불·얼음·자연·비전·그림자·피·성광·물·사랑·폭풍·대지·바람·독·강철)별로 칠합니다. Minecraft는 아이템 텍스처를 가산 혼합하지 않으므로 후광은 밝은 색조로 칠해 어둡게 겹치지 않게 합니다. 외부 셰이더는 필요하지 않습니다.

- 머리 위 문양·섬광·빛기둥은 수직축 빌보드로, 보는 사람이 어느 방향에 있든 정면을 향합니다.
- 1인칭 시야 중앙은 비웁니다. 들고 있는 무기 문양은 오른손 쪽, 타격 섬광은 손 쪽 눈높이 아래, 방어 판은 몸 옆·뒤, 공간 문은 몸 뒤에 둡니다.
- 시간장·룬·나락·중력장은 얇은 범위 링이 실제 판정 반경과 정확히 일치하고, 중심에서 경계까지 충격파가 반복됩니다. 링·충격파는 넓게 펼쳐지므로 256px로 그립니다.
- 개인 강화의 발밑 마법진은 지름 2.3블록 이하로 제한해 범위 효과로 오해되지 않게 합니다. 메구밍의 충전 마법진은 하늘에 떠 있으며, 바깥 10블록 선은 위력 5 폭발의 최대 피해 거리 경고입니다(거리와 장애물에 따라 실제 피해가 달라짐).

식신의 버프 6종은 이름에 맞는 개별 음식 텍스처를 사용합니다. [식신 음식과 공유 규칙](siksin-foods.md), [93개 능력 대상·범위 감사](ability-target-audit.md)를 참고하세요. 일반 음식은 기존 모습이며 팩을 받지 않은 플레이어도 기본 음식으로 사용할 수 있습니다.

빌드는 JDK 21 이상에서 다음과 같이 실행합니다. 문양 원본은 `scripts/effect-art/BuildEffectPack.java`의 Java2D 곡선, 빛 표현은 `VfxPainter.java`, 연출 박자는 `ArtModels.java`에 있습니다. 능력별 모티프·색·동작·속성 팔레트는 `plugin/src/main/resources/effect-art.tsv`에 있습니다.

```powershell
.\gradlew.bat resourcePack --offline
```

결과물은 `build/effect-pack/dist/NewGodWar-Art-<해시>.zip` 하나와 같은 이름의 `.sha1` 파일이며, 문양·팔레트 미리보기는 `build/effect-pack/contact-sheet.png`입니다. 명시적으로 `resourcePack` 작업을 실행할 때만 생성합니다. 메뉴 아트 원본은 `scripts/effect-art/GuiArtwork.java`, 아이콘 미리보기는 `build/effect-pack/menu-icons.png`입니다. 현재 저장소의 `resoucepack/` 디렉토리에서 제공하며 [다운로드와 호환 범위](resource-packs.md)를 참고하세요.

```yaml
abilities:
  effects:
    resource-pack:
      enabled: true
      url: 'auto'
      sha1: ''
```

서버 접속 시 버전에 맞는 팩 다운로드를 제안합니다. 팩 로드 성공 후 새 문양을 표시하며 거부·실패 시 기본 오브젝트, Display 미지원 환경에서는 파티클을 사용합니다. 최신 API는 팩 UUID를 구분하며 구형 단일 팩 API에서는 다른 팩을 동시에 전송하지 않아야 합니다. 1.12~1.13은 전용 아이템 모델 기능이 없어 자동 제안하지 않습니다.

## 오브젝트와 자동 폴백

지원되는 서버에서는 BlockDisplay·ItemDisplay 엔티티로 작은 입체 오브젝트를 구성합니다. 별도 리소스 팩은 필요하지 않습니다. 서버에 Display·개별 가시성 제어 API가 없거나, 생성을 다른 플러그인이 막거나, 엔티티 예산을 초과하면 파티클로 전환합니다. 숫자로 버전을 추측하지 않고 실제 사용 가능한 API를 확인합니다.

| 능력 / 행동 | 오브젝트 연출 | 파티클 폴백 |
| --- | --- | --- |
| 토르 묠니르 | 금속 머리·금색 장식·나무 손잡이가 투척·회수 경로를 따라 이동 | 동일 모델에서 추출한 머리·손잡이 윤곽과 기울기 |
| 오딘 궁니르 / 아테나 반격 | 실제 타격 방향을 향하는 창대·창날 | 가느다란 궤적과 동일한 창날 윤곽 |
| 방어 / 아테나 팔랑크스 | 금색 테두리·반투명 면의 방패, 고정된 다섯 방패 진형 | 같은 위치와 방향의 뾰족한 방패 윤곽 |
| 헤르메스·니케·케찰코아틀 / 주작 | 깃털 날개 / 불꽃색 날개. 비행 중에는 플레이어를 따라 유지 | 깃털 배열 / 불꽃 날개와 이동 잔상 |
| 룬 세공사 | 얇은 삼각·육각 룬과 부유하는 속성 조각 | 화염의 세 갈래 / 서리의 여섯 갈래 룬과 기폭 파편 |
| 아누비스 | 머리 위 금빛 저울, 심판 무게에 맞춰 기울어지는 저울대 | 동일한 저울대·추·접시 윤곽 |
| 중력술사 | 회전하는 중력핵과 주변을 도는 세 조각 | 중심으로 모이는 세 입자 흐름 |

오브젝트 장면이 성공하면 해당 장면의 파티클 폴백은 출력하지 않습니다. 낙뢰·기폭처럼 별도의 실제 타격 단계는 유지합니다. 같은 장면을 갱신할 때 기존 엔티티를 이동시키므로 복제 잔상이 쌓이지 않습니다.

짧은 행동 연출이 파티클로 시작하면 그 장면이 끝날 때까지 같은 방식을 유지합니다. 중간에 오브젝트 예산이 확보되어도 입체 모델로 바꾸며 동작을 처음부터 재생하지 않습니다. 방패·날개는 파티클에서도 같은 모델의 좌표를 사용하며, 몸에 붙는 방패·날개·저울·월계관은 위아래 시선에 따라 기울지 않습니다.

오브젝트는 충돌·중력·드롭이 없는 시각 전용 Display입니다. 월드에 저장하지 않으며 장면 만료, 접속 종료, 사망, 월드 변경, 능력 해제, 플러그인 종료 시 회수합니다. 비행 날개는 착지 시 회수합니다. 같은 월드의 32블록 이내에서 허용된 관전자에게만 표시하고, 유지 중에도 가시성을 다시 확인합니다. 기본 세션 상한은 조각 48개, 전체 서버 상한은 256개입니다.

## 중복 방지와 표시 위치

- 같은 틱의 여러 상태 반응은 대상마다 핵심 반응 하나로 합쳐 다음 틱에 출력합니다. 시전자 동작과 수신 반응은 별도로 유지해 자신의 회복·강화 반응이 시전 소품을 지우지 않습니다. 같은 역할·대상의 반복 반응 간격은 0.2초이며 안내 메시지는 별도로 제한합니다.
- 토르·메아리 검사·헤르미온느 등 전용 연출이 있는 기술에는 일반 시전 문양이나 자동 상태 문양을 더하지 않습니다. 주문·행동별로 필요한 반응을 직접 지정합니다.
- 회복은 회복받은 대상, 속박은 발목, 수면은 머리 위, 장비 생성·수리는 손, 방패는 전방, 날개는 등 뒤에 붙습니다. 시전 소품은 시전자 방향에 따라 회전합니다. 피격 반응은 대상의 시선 대신 공격이 들어온 방향을 유지합니다.
- 유지 중인 같은 강도의 버프를 갱신할 때에는 연출을 반복하지 않습니다. 처음 적용되거나 강도가 바뀔 때 표시합니다.
- 전용 반응은 최대 24조각이며, 세션에서 동시에 최대 8장면을 유지합니다. 파티클 대체 연출은 장면당 최대 64점, 4틱 간격, 최대 5프레임으로 제한합니다. 기존 참격·보조 반응은 작은 기본 입자를 유지합니다. 오브젝트 세션/전체 상한도 함께 적용됩니다.
- 같은 월드의 32블록 이내에 표시합니다. 은신 계열 시전·숨긴 폭탄은 본인에게만 보입니다. 실제로 효과를 받은 사람은 자기 몸의 반응을 볼 수 있으며, 투명 대상의 반응은 대상 자신에게만 표시해 주변에 위치를 드러내지 않습니다.
- 지연 반응은 출력 직전에 접속·생존·월드·가시성을 다시 확인합니다. 능력 해제 시 예약된 반응을 취소합니다.

전체 연결·판정 규칙은 [93개 실행 연결표](ability-presentation-design.md)를 참고하세요.

## 설정과 호환성

- `abilities.effects.objects: true` (기본): 지원 서버에서 오브젝트를 우선 사용합니다. `false`로 바꾸면 파티클 전용 모드입니다.
- `abilities.effects.object-limit: 48` (기본): 능력 세션별 오브젝트 조각 예산입니다. 0~96으로 제한되며 0이면 파티클로 전환합니다.
- `abilities.effects.particles: false`: 추가 입자와 파티클 폴백을 끕니다. 지원 서버의 오브젝트는 별도로 유지됩니다.
- `abilities.effects.enabled: false`: 오브젝트·입자·추가 소리·화면 안내를 끕니다. 실제 번개·폭발·지형 변화는 게임 효과이므로 유지됩니다.
- `abilities.effects.animations: false`: 짧은 행동별 디자인을 완성된 정지 형태로 한 번 표시하고 투사체 궤적·비행 잔상을 끕니다. 묠니르의 실제 이동과 시간장·벌떼 같은 기술 자체의 전용 장면은 유지됩니다.
- `abilities.effects.sounds`, `action-bar`: 각각 추가 소리·액션바를 제어합니다. 능력 발동 중앙 타이틀은 사용하지 않습니다. `abilities.messages.compact`는 기본 `true`이며 반복 발동·패시브·초 단위 카운트다운을 생략합니다. 실패·재사용·충전 수치·선택 모드·중요 버프 결과·위험 예고·효과 시작/종료는 짧게 유지합니다. 상세 안내는 `/gw gui display`에서 간결한 전투 안내를 끄면 표시됩니다.
- 1.12.2에서는 Display 엔티티를 로드하지 않고 파티클 경로를 사용합니다. 기본 입자 종류는 1.12와 최신 버전 이름을 모두 처리합니다. 뿌리·자물쇠·수면 표시와 오브젝트 윤곽 폴백은 1.12에서 RGB 오프셋, 이후 버전에서 DustOptions를 사용합니다.

## 검증 범위

자동 검사는 실제 Paper 월드의 Display 생성·이동·정리와 기록용 관전자 객체가 받는 파티클·표시 명령을 확인합니다. 네 방향과 위/정면/아래 시선, 이동 중 날개 재사용, 거리 이탈·복귀, 사망·접속 종료, 연출 도중 예산·설정 변경도 검사합니다.

서버 검사 외에 숨김 Minecraft 26.3 클라이언트의 원본 프레임으로 리소스팩 표시와 연속 애니메이션을 촬영합니다. 모델 재생과 실제 능력 시전은 보고서에서 구별합니다. 93개 능력의 모든 플레이어 조합을 영상으로 검증한 것은 아닙니다. 파티클 대체 표현은 텍스처와 질감이 다르며, 다른 리소스팩·셰이더 조합은 별도 확인이 필요합니다.
